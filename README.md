# CR League Manager

A local desktop app for managing Clash Royale tournaments. The app uses Electron for the desktop window, a React and TypeScript frontend, an Express API, and MySQL for data storage.

## Requirements

- Node.js 22 (the expected version is recorded in `.node-version`)
- npm
- MySQL, configured with a database and user for the app
- Docker, if you use the provided Windows launcher (`start-app.bat`)

## First-time setup

1. Install the root dependencies:

   ```powershell
   npm install
   ```

2. Install backend dependencies:

   ```powershell
   npm install --prefix backend
   ```

3. Install frontend dependencies using the package manager and lockfile configured for the frontend. The frontend currently has a `pnpm-lock.yaml` and uses Vite Plus; check its package-manager setup before installing.

4. Configure the backend database. Create `backend/.env` with:

   ```dotenv
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=your_mysql_user
   DB_PASSWORD=your_mysql_password
   DB_NAME=your_database_name
   ```

   Keep credentials private; `.env` files are ignored by Git. The backend expects the database and schema to exist. See `backend/src/schema/` for the schema and migrations, and `backend/src/seeds/` for seed data.

## Run in development

Start the Electron app, frontend development server, and backend together:

```powershell
npm run dev
```

To run parts separately, use separate terminals:

```powershell
npm run dev:backend
npm run dev:frontend
npm run dev:electron
```

For the web frontend and API without Electron:

```powershell
npm run dev:web
```

The backend API listens on port `3000` by default. The frontend development server proxies `/api` requests to it. The backend starts its API even if MySQL is unavailable, but database-backed features require a working database connection.

On Windows, `start-app.bat` starts the Docker container named `mysql-container` (as set in `dev-config.bat`) and then runs the development app. Update that container name if your MySQL container uses another name.

## Build and package

Build the backend and frontend:

```powershell
npm run build
```

Create a distributable Windows installer:

```powershell
npm run dist
```

Packaged output is written to `release/`. Build output in `backend/dist/` and `frontend/dist/` is generated by the build commands.

## Backend verification

The integration verifier is in `backend/scripts/verify-game-flow.mjs`. Its safety requirements, test database setup, and covered checks are documented in `backend/VERIFICATION.md`. Use a dedicated database whose name ends in `_test`; do not point the verifier at a database with real data.
